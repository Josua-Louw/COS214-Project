\doxysubsection{Detailed Description}
Abstract base class representing an orderable plant. 

The \doxylink{classOrderPlant}{Order\+Plant} class serves as an abstract base class for all orderable plants in the system. It defines the interface for getting the price, decorating the plant, and retrieving the type of the plant. Derived classes must implement these methods to provide specific behavior for different types of orderable plants. \begin{DoxyNote}{Note}
This class is abstract and cannot be instantiated directly. 
\end{DoxyNote}
