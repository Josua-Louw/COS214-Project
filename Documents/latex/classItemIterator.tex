\doxysubsection{Detailed Description}
Concrete iterator that traverses \doxylink{classItem}{Item} nodes inside \doxylink{classGreenHouse}{Green\+House} section(s). 

Iterates through a collection of \doxylink{classItem}{Item} pointers (e.\+g., pots, decorations, or seed packets). \begin{DoxyNote}{Note}
This class inherits from the abstract \doxylink{classIterator}{Iterator} class. 
\end{DoxyNote}
