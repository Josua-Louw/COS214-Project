\doxysubsection{Detailed Description}
Concrete staff class for managing task distribution in the \doxylink{classPlant}{Plant} Nursery Simulator. 

Inherits from \doxylink{classStaff}{Staff} to handle task distribution, implementing the \doxylink{classCommand}{Command} pattern (FR5) via receive\+Command to store unhandled commands. Participates in the Chain of Responsibility Pattern (FR6) as the final handler, queuing commands when no staff are available and redistributing them via \doxylink{classNurseryHub}{Nursery\+Hub} (FR7).
