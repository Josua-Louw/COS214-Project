\doxysubsection{Detailed Description}
Abstract Mediator in the Mediator design pattern. 

Declares the operations used by colleagues to notify the mediator about events and to request assignments. Concrete mediator (\doxylink{classNurseryHub}{Nursery\+Hub}) implement how events are routed and how commands are assigned.
