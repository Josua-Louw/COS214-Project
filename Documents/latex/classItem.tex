\doxysubsection{Detailed Description}
Abstract base class representing a generic item in the greenhouse system. 

The \doxylink{classItem}{Item} class provides a common interface for all items in the greenhouse system, allowing for retrieval of the item\textquotesingle{}s name. It is an abstract class with a pure virtual method for getting the name, which must be implemented by derived classes. \begin{DoxyNote}{Note}
This class is abstract and cannot be instantiated directly. 
\end{DoxyNote}
