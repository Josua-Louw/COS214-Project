\doxysubsection{Detailed Description}
Declaration of the \doxylink{classWindow}{Window} class for the Greenhouse Management System GUI. 

This class manages the main window of the application, including layout and navigation between different sections such as \doxylink{classPlant}{Plant} Management, \doxylink{classStaff}{Staff} Management, \doxylink{classOrder}{Order} Processing, and Greenhouse View.
