\doxysubsection{Detailed Description}
Concrete staff class for managing plant care in the \doxylink{classPlant}{Plant} Nursery Simulator. 

Inherits from \doxylink{classStaff}{Staff} to handle plant care tasks, implementing the \doxylink{classCommand}{Command} Pattern (FR5) via receive\+Command to process commands like \doxylink{classWaterPlant}{Water\+Plant} and \doxylink{classFertilizePlant}{Fertilize\+Plant}. Participates in the Chain of Responsibility Pattern (FR6) by receiving delegated tasks via next\+Staff. Interacts with \doxylink{classPlant}{Plant} and \doxylink{classNurseryHub}{Nursery\+Hub} (Mediator, FR7) to update plant states.
