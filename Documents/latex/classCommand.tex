\doxysubsection{Detailed Description}
Abstract base class for the \doxylink{classCommand}{Command} Pattern in the \doxylink{classPlant}{Plant} Nursery Simulator. 

Encapsulates staff tasks (e.\+g., watering, fertilizing, selling) as command objects, allowing tasks to be stored, executed, and potentially undone. Commands are assigned to \doxylink{classStaff}{Staff} via \doxylink{classNurseryHub}{Nursery\+Hub} (Mediator) and stored in \doxylink{classStaff}{Staff}\textquotesingle{}s task\+List. This pattern decouples task requests from their execution, enabling flexible task management.
