\doxysubsection{Detailed Description}
Abstract base class for plant implementors. 

The \doxylink{classPlantImplementor}{Plant\+Implementor} class provides a common interface for all plant implementors, allowing for cloning of plant implementor objects. It is an abstract class with a pure virtual method for cloning, which must be implemented by derived classes. \begin{DoxyNote}{Note}
This class is abstract and cannot be instantiated directly. 
\end{DoxyNote}
