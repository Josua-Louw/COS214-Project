\doxysubsection{Detailed Description}
Represents a customer who can place orders in the nursery system. 

The \doxylink{classCustomer}{Customer} class utilizes multiple \doxylink{classOrderBuilder}{Order\+Builder} instances to create orders for different types of items available in the greenhouse. It communicates with the \doxylink{classNurseryMediator}{Nursery\+Mediator} to retrieve item lists and place orders. \begin{DoxyNote}{Note}
The \doxylink{classCustomer}{Customer} class is responsible for managing its own order builders and coordinating the order creation process. 

Represents the director in the Builder design pattern. 
\end{DoxyNote}
