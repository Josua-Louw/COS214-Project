\doxysubsection{Detailed Description}
Abstract class for building parts of an order in a greenhouse management system. This class defines the interface for building specific parts of an order based on plant types. 

\begin{DoxyNote}{Note}
This class needs a pointer to a \doxylink{classGreenHouse}{Green\+House} object to access plant data. 

Derived classes must implement the build\+Part and check\+Type methods.

The build\+Part method falls under the Builder Design Pattern. 

The check\+Type method falls under the Template Method Design Pattern which is a step in the process. 
\end{DoxyNote}
