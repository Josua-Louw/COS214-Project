Detailed Description

Concrete staff class for managing task distribution in the Plant Nursery Simulator.

Inherits from Staff to handle task distribution, implementing the Command pattern (FR5) via receiveCommand to store unhandled commands. Participates in the Chain of Responsibility Pattern (FR6) as the final handler, queuing commands when no staff are available and redistributing them via NurseryHub (FR7).
