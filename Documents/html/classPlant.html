Detailed Description

Class representing a plant in the system.

The Plant class provides a common interface for all plant types, managing their properties such as price and implementor type. It inherits from GreenHouse, integrating with the greenhouse framework.

See also
GreenHouse, PlantImplementor, GreenHousePlant, OrderPlant
