Detailed Description

Abstract class for building parts of an order in a greenhouse management system. This class defines the interface for building specific parts of an order based on plant types.

Note
This class needs a pointer to a GreenHouse object to access plant data.
Derived classes must implement the buildPart and checkType methods.
The buildPart method falls under the Builder Design Pattern.
The checkType method falls under the Template Method Design Pattern which is a step in the process.
